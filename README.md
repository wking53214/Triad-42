# Triad+42

An advisory cognitive review harness for structured adversarial examination, independent structural analysis, real-world grounding, and disciplined synthesis.

Triad+42 is designed to organize distinct modes of review while preserving their separation, sequence, provenance, and epistemic status.

The framework consists of three review lenses followed by a separate synthesis stage:

1. RED — adversarial examination.
2. GRAY — independent structural examination.
3. GREEN — real-world grounding.
4. 42 — disciplined novelty synthesis.

The framework does not perform the underlying reasoning. A human or external reasoning system supplies the analysis. Triad+42 governs how that analysis is recorded, sequenced, classified, escalated, and preserved.

The individual review techniques are not intended to function as interchangeable labels for the same activity. Each stage has a distinct epistemic purpose.

## The Four Review Functions

### RED — Adversarial Examination

Red deliberately attacks assumptions, identifies weaknesses, searches for contradictions, and attempts to expose failure conditions.

Red findings carry explicit severity:

- critical;
- high;
- medium;
- low.

Severity is assigned by the reviewer rather than automatically determined by the harness.

Triad+42 does not allow the volume of findings to substitute for judgment.
